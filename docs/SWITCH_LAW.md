# TS2SC v10.2 · 开关法则：完全继承的可验证定义

日期：2026-11-28 · `passed = true` · 审计耗时 0.5 s

> 指令：**「完全的继承所有能力（开关法则，开门禁继承，不开就原模型能力）」**
> 本轮把这句从一句口号变成一条可复验的等式、一份权威注册表和一套真跑判据。

---

## 1. 法则（形式化）

```
y = T(x) + 𝟙[master] · Σ_f  s_f · Δ_f(x)

master      = gate.beta / set_beta(β_l)
s_f ∈ [0,1]  24 层 × 13 门，逐层独立
全关         s_f = 0 ∀f  ⇒  y ≡ T(x)  逐位（结构性 early-return）
全开         s_f = 1 ∀f  ⇒  与 v10.1 逐位相同（27/27 Δ 快照）
```

**关键设计**：全关态走与 `β=0` **完全同一条 early-return**，不是「参数恰好乘成 0」。
所以「不开就原模型能力」是结构保证，不是靠数值撞出来的。
`all_off()` 之后即使再调 `set_beta(1.0)` 也不复活（判据 A 实测）。

**数值中性**：`cap == 1.0` 时 `_scaled()` 直接返回原对象、**零运算**。
所以默认交付态（全开）与 v10.1 逐位相同 —— 权重字节、manifest、
2 个分片、219/219 全量 COPY 审计、4 语言 10 臂生成、`T==C0` 端到端
零回归**一个没动、全部仍有效**，本轮没有重跑 20 分钟生成。

## 2. 权威注册表：`capability_registry.json`

| 类别 | 数量 | 开关含义 |
|---|---|---|
| **FORWARD** | 20 | 13 个可差分前向门，单门关必改变 Δ |
| **CONTRACT** | 9 | 理论前提 / 工程契约 / 声明边界，开关只控制登记与校验，**不进 hook** |
| **DEFERRED** | 2 | 无词表设计：源码中核实不存在、用户确认未推送，**置 True 被显式拒绝** |

9 个 CONTRACT 项：输入侧 bit 预算、H6–A4 归一化接口、门控巩固 / Twb、

**「完全继承」的准确口径**：
每一项都有可切换 slot **且**全关逐位回到原模型。
**不等于** 31 项都在前向贡献数值，**不等于**定理在 LM 上复现，
**不等于**能力变强。2 项 DEFERRED 明确未继承，不假装。

## 4. 与「开→继承 / 关→不继承」历史观察对齐

这条法则正好把 1.7B 时代那三句观察变成机器判据：

- 全关 ⇒ `T==C0` 端到端逐 token 相同（原能力完整保留）
- 单门开 ⇒ 该能力 Δ≠0（显式开启才继承）
- 手动关的特性 ⇒ 对应门 `s_f=0`，不继承
- 因为全是**人工显式门**，仍**不是** ungated self-evolution 证据

## 5. 边界（不删减）

- β=1 仍是**尺度契约配置**，不是 L2 校准成品；`calibrate_beta_v10.py`
  仍 `NOT_EXECUTED`，`P-β` 仍 `NOT_TESTED`。`gate.beta` 现在是
  `beta_l.json` 的真正写回落点。
- 端到端 **8M 仍 INFEASIBLE**（hybrid 保留 teacher 全注意力，192 GiB KV），
  只有分支 O(1) 状态性质成立。
- 上游 `COMPLETE_BEYOND=False` / 2× 对手步数否决随附，**不继承超越主张**。
- 无 LM / ppl / 吞吐 / SOTA / 原生级声明；无新生成样本、无配对 CI。
- 本轮纯 numpy CPU 单元级，未拉 2 GiB 权重、未跑 GPU forward。
- 权重、分片、manifest **字节一个没动**；未删除任何云端条目。
