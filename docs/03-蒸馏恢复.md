# 03 · 蒸馏恢复：为什么必须做，怎么做

## 一、问题的定量描述

裸迁移的失真**全部**在 mixer：

```
① teacher 注意力输出 vs 迁移后 mixer 输出    余弦 0.1024
② teacher 整层 vs [teacher注意力→迁移后FFN]  余弦 1.0000
③ teacher 整层 vs 迁移整层                   余弦 0.0570
```

①②③ 放在一起读：**FFN 完美，mixer 全丢，端到端被 mixer 拖垮。**

---

## 二、为什么不能靠调参解决

试过的两条路，都无效：

| 尝试 | 结果 |
|---|---:|
| 修 `coef` 形状 bug（之前根本没载入） | 0.0655 → 0.0347 ❌ |
| 开 `content_gate` 补偿 | 0.0347 → 0.0573 ❌ |

**根因（机理层面）**：

```
Attention:  out[pos] = Σ_τ A(pos, pos-τ) · V[pos-τ]
            ↑ A 依赖输入内容（Q·Kᵀ），每个 token 的路由不同

SGC:        out[pos] = Σ_τ Ψ[τ] · V[pos-τ]
            ↑ Ψ 固定，不依赖输入
```

**这是"输入相关" vs "输入无关"的数学鸿沟，参数层面无法跨越。**

唯一出路：**让 mixer 学会一个在"平均意义上"最优的固定核，
再把可学习的内容路由能力交给 FFN 和后续层去补偿。**

---

## 三、A1.0 的失败：用随机高斯当输入

A1.0 的做法：

```python
x = torch.randn(1, SEQ, D) * sigma    # ← 错的
```

真实激活的两个性质，高斯都不满足：

1. **低秩**：Transformer 残差流的有效秩远小于 D
2. **各维相关**：不同维度强相关，不是独立同分布

结果：蒸馏出的 mixer 在真实数据上可能完全不 work。

**实测改进**：

| 版本 | 输入 | 195 步效果 |
|---|---|---:|
| A1.0 | 随机高斯 | 0.42（100 步） |
| **A2.0** | **teacher 真实激活** | **0.6659（195 步）** |

## 四、A2.0 的做法

### 阶段 1：缓存真实激活

```python
# 从 teacher embedding 里随机抽行 —— 每行都是真实 token 的向量
ids = torch.randint(0, V, (1, SEQ))
x = teacher_emb[ids].float()          # 真实分布

# 逐层前向，缓存每层的输入 X[i] 和输出 Y[i]
for i in range(L):
    X[i] = x.clone()
    Y[i] = teacher_block(x, w, i, pos)
    x = Y[i]
```

**一次前向，28 层全缓存，落盘。之后所有训练直接读盘。**

### 阶段 2：逐层蒸馏

```python
for i in range(L):
    unit = build_single_layer()        # 单层 SimplCore
    load_migrated_weights(unit, i)     # 装入迁移来的权重
    freeze_ffn_and_norm(unit)          # ★ 冻结 86.6%
    train_mixer_only(unit, X[i], Y[i])
```

### 关键：loss 必须归一化

**实测残差流的尺度变化**：

| 层 | σ | max |
|---:|---:|---:|
| 0 | 0.0293 | 0.155 |
| 27 | **33.78** | **7187** |

**相差 1000 倍。** 不归一化的话：

```
layer 27 的 MSE ≈ 33² ≈ 1100
layer 0  的 MSE ≈ 0.03² ≈ 0.001
```

深层梯度直接爆掉。

**修法**：

```python
YS = float(Y.std())
loss = F.mse_loss(out / YS, Y / YS)
```

## 六、超参建议

| 参数 | 值 | 说明 |
|---|---|---|
| `RA_LR` | 3e-3 | 只训 mixer 可以激进些 |
| `RA_STEPS` | 300/层 | layer 0 实测 195 步仍未收敛，可加到 500 |
| `RA_SEQ` | 64 | 序列长度，2 核 CPU 下的平衡点 |
| `RA_N` | 8 | 训练样本数，太多会拖慢 |
| 优化器 | AdamW | |
| 调度 | CosineAnnealing，eta_min = LR×0.05 | |
| 梯度裁剪 | 1.0 | 必须，残差流容易爆 |

---

## 七、真机（GPU）建议

- batch 可以开大，`RA_N` 从 8 → 64+，样本多样性直接决定泛化
- 层数可以并行：不同层之间**没有依赖**，28 层可以 28 张卡同时跑
- `RA_SEQ` 可以开到 2048+，长程依赖学得更准
- 全部 28 层在 2×MI210 上预计 **< 1 小时**
