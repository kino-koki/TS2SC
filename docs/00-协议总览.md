# 00 · A2.0 协议总览

## 什么是 A2.0

A2.0 是把 Transformer 预训练模型迁移到 SimplCore 的**五阶段流水线协议**。
"A" 指 Architecture 转换；"2.0" 是第二版——第一版只做权重搬运，
第二版加入了**真实激活蒸馏**这个决定性阶段。

```
S1 规划   →  S2 权重迁移  →  S3 激活缓存  →  S4 逐层蒸馏  →  S5 验证
纯计算      直搬/变换/重组   一次 teacher    只训 mixer      五项测试
秒级        分钟级           前向            小时级          分钟级
```

---

## 五阶段详解

### S1 · 规划

不加载任何权重，纯算术。用于**在花钱跑之前先确认几何可行性**。

关键判断：
- FFN 中间维是否对齐（对齐 = 直搬，省掉最容易出错的一步）
- 词表是否一致（不一致 = embedding 必须变换或重建）
- GQA 的 KV 头数（决定 in_proj / gate_proj 怎么派生）

### S2 · 权重迁移

| 通道 | 条件 | 做法 |
|---|---|---|
| **① 直搬** | 形状完全一致 | 逐位复制 |
| **② 变换** | 形状不同但有确定性映射 | 切片 / 扩维 / 降维 |
| **③ 重组** | teacher 层数不足 | 两层确定性凸组合 |

**实测**：99.84% 参数逐位保留，199/199 张量逐位比对全中。

### S3 · 激活缓存（A2.0 相对 A1.0 最关键的改进）

A1.0 用随机高斯当训练输入 —— **错的**。
真实激活是低秩且各维相关的，高斯不是。

A2.0：**一次 teacher 前向，把 28 层真实激活全部缓存到磁盘**。
输入用 teacher embedding 里随机抽的行（每行都是真实 token 的向量），
分布 100% 真实。

**实测改进**：A1.0 100 步 0.4157 → A2.0 195 步 **0.6659**。

### S4 · 逐层蒸馏

- 冻结 FFN / embedding / norm（86.6% 参数，零反向开销）
- 只训 mixer（13.4%）
- 用 teacher 整层输出做 MSE 回归目标
- **每 5 步存检查点**，中断后自动 resume

### S5 · 验证

见 [04-能力验证](04-能力验证.md)。

## 术语表

| 术语 | 含义 |
|---|---|
| **teacher** | 被迁移的源 Transformer 模型 |
| **student** | 迁移后的 SimplCore 模型 |
| **mixer** | SimplCore 里替代 Attention 的谱卷积模块（SGC） |
| **FFN** | SwiGLU 前馈网络，SimplCore 与 Transformer **结构同构** |
| **直搬** | 形状一致直接逐位复制 |
| **核拟合** | 把注意力按相对距离平均成卷积核，再用 SGC 基函数拟合 |
| **裸迁移** | 只做 S2、未蒸馏的状态 |
| **保真度** | teacher 输出 vs student 输出的余弦相似度 |

## 设计哲学

### ① 不追求"零损失迁移"，追求"可恢复的起点"

Attention→SGC 的失真是**数学上不可能消除的**（输入相关 vs 输入无关）。
A2.0 不假装能消除它，而是：

- 把它**精确定位**到 13.4% 参数上
- 让 86.6% 参数**保持逐位等价**（余弦 1.0000）
- 用最短路径（只训 mixer）把 13.4% 补回来

### ② 所有静默失败都要能被检测

本项目的 bug 全部**不报错**：形状不匹配静默跳过、bf16 更新被舍入、
层号取错只迁一层……见 [06-踩坑记录](06-踩坑记录.md)。

A2.0 要求每个阶段都有**断言**和**覆盖率报告**（`loaded/total` 必须打印）。

### ③ 可续跑优先于速度

2 核 CPU 环境，长任务必然被中断。
所有训练脚本都设计成**每 5 步存盘 + 外层 shell 循环拉起**。

## A1.0 → A2.0 变更

| 项 | A1.0 | A2.0 |
|---|---|---|
| 训练输入 | 随机高斯 | **teacher 真实激活** |
| 目标 | Attention 分支输出 | **整层输出** |
| loss | 裸 MSE | **除以 σ 归一化** |
| 恢复效果 | 100 步 → 0.4157 | **195 步 → 0.6659** |
| 保存粒度 | 100 步 | **5 步** |
