# 原生 SimplCore：真做了什么，没做到什么

日期 2026-11-28 · 本轮结论：**没有交付冒充品**

---

## 0. 先认账

> 「β>0 时其实只是 hybrid，不是 SimplCore 的？」——**是。**

`y = T(x) + 𝟙[master]·Σ s_f·Δ_f(x)` 里 `T(x)` 就是 Llama 全注意力；
219 个 teacher 张量逐位 COPY、96 个 `self_attn` 一个没摘；β=0 关掉旁路
逐 token 退回原模型；10M 端到端 240 GiB KV 判 `INFEASIBLE_LEDGER`。
旁路再纯，引擎仍是注意力。之前把「旁路纯」讲成「模型纯」，是糊弄。

---

## 1. 真正去做了：纯 O(1) 无注意力主干（`pure_backbone_v11.py`）

推理链彻底摘除注意力：`pure.*` 命名空间、冻结谱核
`ψ_m[τ]=ρ^τ·sin((τ+1)θ)` + Shift-Misalign 融合 + 二阶凹门控 +
定长谱卷积 + γ 记忆 + SwiGLU。**没有 Q/K/V、没有 SDPA、没有 KV cache、
没有位置维 softmax。**

`verify_pure_v11.py` 真跑，**C1–C8 全绿（`passed=True`）**：

| 判据 | 结果 |
|---|---|
| C1 路由纯度 | 243 个 `pure.*` 张量 ∩ teacher 219 = **0**；与 219 个 COPY 的 sha256 集合 **0 碰撞**；禁止模式 0 命中 |
| C2 算子纯度 | 无 KV cache、无 banned call、无注意力属性 |
| C3 O(1) 状态 | L=1 与 10M 后恒为 **2,041,973,952 B**（每层 85,082,248 B），不随 L 增长 |
| C4 10M 实跑 | `advance_idle(10M)` 闭式 **0.0 s**，之后 logits 全 finite |
| C5 关外挂不退化 | 删谱核 Δlogits **1.21e−4**、删谱卷积 **2.54e−6**、删 γ 记忆 **1.38e−6**，三者删除后仍 finite / 仍无注意力 / **恢复后 Δ<1e−9** |
| C6 非退化 | 3 组输出互不重复，复读率 0.0 |
| C7 结构自检 | 24 层 × 3 对象扫描，violations 0 |
| C8 长程衰减（如实登记） | ρ=0.9995 ⇒ ρ^10M 下溢，ψ(0)=1.2203 → ψ(10M)=**0.0**。O(1) 状态恒定 ≠ 长程谱响应保留 |

**过程中抓到并修掉 4 个真问题**（都写进代码/报告，没抹平）：
① `θ_base=1e-4` 让 ψ(0)≈1e-4 谱核在初态被数值吞掉 → 改 0.3；
② 谱核乘性注入被零记忆吞掉 → 改加性；
③ C4 的 10M 跳跃让 ρ^L 下溢，复用同一对象测 C5 导致「删谱核 Δ=0」的假象
→ C5/C6 改独立初态对象（并由此发现 C8）；
④ `tensor_sha256()` 的 `.tobytes()` 复制 802 MiB 触发 OOM → 改零复制
`memoryview.cast('B')` 流式哈希；单进程只持有一个 1.6 GiB 模型。

## 2. 但「严格保留原模型能力」实测 **没做到**

`align_pure_ability.py` 分两进程真跑（teacher 阶段 LIVE 拉 22 分片 /
2.01 GiB 全 blob-sha 校验，6 个中英 prompt 取真实权重 pre-head hidden 与
next-token 分布；pure 阶段同 token id 序列前向）：

**`ABILITY_PRESERVED = False`**

| 指标 | 实测 | 门槛 |
|---|---|---|
| 原始 hidden cos 均值 | **−0.0138** | — |
| argmax 一致率 | **0 / 6** | ≥ 0.90 |
| top-5 重叠 | **0 / 6** | — |
| ridge 训练集 cos 均值 | 0.7759 | — |
| **ridge held-out cos** | **0.7612** | ≥ 0.90 |
| **不同前缀下 pure 的 argmax 种类** | **1 / 6** | — |
| 不同前缀 hidden 方向 cos 最低 | **0.999999** | — |

最硬的一条不是 cos，是**前缀信息坍缩**：6 个不同 prompt，纯主干的
最终 hidden 方向几乎完全相同（cos ≥ 0.999999）、argmax 全是同一个 id。
随机初始化下 FFN 增益相对 embed 行过小，O(1) 状态根本没把历史送进
最终表示。这不是调参能救的，是**函数类不对**。

## 3. 为什么三条约束「不训练」就不可同时成立

设 teacher 函数 `T`、纯主干函数 `P`。

1. **非 hybrid** ⇒ 推理链里没有 `T(x)`，只有 `P(x)`。
2. **严格保留能力** ⇒ 在全部输入分布上 `P(x) ≈ T(x)`（生成级一致）。
3. **迁移（COPY 权重）** ⇒ 不重新求参数。

teacher 的语言知识内化在 96 个 `self_attn` 的 Q/K/V/O 权重里，而那些
权重**只在 softmax-attention 算子下才有意义**。换算子 = 换函数类：
attention 是内容寻址的二次交互，冻结谱核是固定核 LTI，两者的归纳偏置
不同。逐位 COPY 只能在**同一个算子**下保持函数不变；算子一换，
`P` 就是另一个函数，没有理由等于 `T`。

实测支持：原始 cos ≈ 0（正交）、线性 ridge 只能把 5 个训练 prompt 插值到
0.776、held-out 掉到 0.761，且前缀信息坍缩。**线性对齐都不够，必须改参数。**

所以唯一解是：**架构转换 + 逐层知识蒸馏**——用 teacher 24 层 hidden 作
监督，在真实语料上训练纯 SGC 层。那已经不是「迁移」，是「重新训练原生模型」。

## 4. 唯一路径（GPU，本沙盒无算力，不伪造）

见 `DISTILL_PROTOCOL.md`。要点：

- 监督：teacher 每层 pre-/post-attn hidden → 纯层对应 hidden，逐层 MSE + cos；
  末端 logits KL + 生成级 argmax 配对。
- 数据：真实语料 ≥ 数十 M token（不是 6 个 prompt）。
- 验收：held-out hidden cos ≥ 0.90、生成 argmax 一致率 ≥ 0.90、
  配对 Wilson CI 下界 > 0、下游 benchmark 不劣。
- 代价：1B 级 24 层蒸馏需多卡数天；CPU 沙盒做不到，本轮**不画饼**。
