## 结论先行

**分两种口径，结论不同，不能一句「是」糊过去：**

- **按 A2.0 严格定义**（mixer **替代** Attention + 真实激活蒸馏）：**不是**。A2.0 术语表：mixer = SimplCore 里【替代 Attention】的 SGC。当前 v8.x 是『融合不替换』：teacher self_attn / QSA / norms / FFN 一层不删，SGC 是并联加性分支（out = teacher_block + β·sgc_branch）。S3/S4 未执行，没有核拟合蒸馏，也没有 A2.0 的 mixer 余弦 0.1024→0.6659。所以它不是 A2.0 意义上的 student。
- **按 A2.0 的底线与验收纪律**：**全部符合，且是 S2 的严格超集**。保留原词表 ✓ / FFN 对齐且逐位 ✓ / 无静默跳过（UNCLASSIFIED=0）✓ / 覆盖率 219/219=100% > 99% ✓ / FFN 保真度 =1.0 ✓ / SGC 分支 O(1) 状态 ✓ / 每个阶段都有断言与账本 ✓。它是 A2.0 S1+S2 完成、S3–S4 尚未启动的【融合态前置阶段】。

**这两者不矛盾：你此前明确要求『融合而非替换、绝不进 mixer 转移矩阵』，A2.0 替换态会直接破掉这条红线（也破掉 β=0 逐位零回归）。所以当前是**有意选择的另一阶段**，不是迁移失败。**

## 一、A2.0 要求「必须打印的三个数字」

| # | 协议要求 | 本迁移体实测 | 判定 |
|---|---|---|---|
| 1 | loaded / total > 99%（否则有张量静默跳过） | 219/219 = 100.00% | ✅ |
| 2 | FFN 保真度余弦 ≈ 1.0000 | 1.0000（逐位相同 ⇒ 余弦严格 = 1.0） | ✅ |
| 3 | O(1) 唯一状态数 = 1（否则架构没生效） | SGC 分支 True（24 层恒定 36.281 MiB）；端到端 hybrid False（8M 时 teacher KV ≈ 192.0 GiB） | ✅ |

> **loaded / total > 99%（否则有张量静默跳过）** — A2.0 原始实测 99.84% / 199-of-199。本迁移体是 teacher 侧 219/219 逐位 COPY、UNCLASSIFIED=0、removed=0，比 99.84% 更强（严格逐位，非余弦近似）。注意 student 另有 192 个新增 sgc/blocks 张量，不计入 teacher 覆盖率分母。

> **FFN 保真度余弦 ≈ 1.0000** — A2.0 铁律 2 要求 FFN 对齐（c.ffn_ratio=3.0）。本迁移体走『融合不替换』：FFN / SwiGLU / norms / embed / lm_head 全部逐位 COPY，没有走 A2.0 的切片/扩维/重组，所以不存在形状不匹配导致的静默跳过。

> **O(1) 唯一状态数 = 1（否则架构没生效）** — 按 A2.0『mixer 替代 Attention』的严格口径，这一条只对 SGC 分支成立；teacher 全注意力一层未删 ⇒ 端到端状态仍随 L 线性增长。这是融合态与替换态的分界线，不粉饰。

## 二、三条铁律

| 铁律 | 状态 | 证据 |
|---|---|---|
| 铁律 1：保留原词表 —— 换词表 = 毁模型 | 符合 | vocab_size=130560 保留；embed_tokens / lm_head 全 COPY；contract I6 校验 len(tok)==embed.rows |
| 铁律 2：FFN 必须对齐 c.ffn_ratio = 3.0 | 符合（更强） | FFN 全部逐位 COPY，未做任何 ratio 变换 |
| 铁律 3：loss 必须归一化（残差流逐层放大 1000×） | 不适用 / 未触发 | 本路线未做 S3/S4 蒸馏，无训练 loss；上线时靠 F25 无量纲尺度契约 ‖Δ‖≤βε‖x‖ 防放大 |

- 铁律 1：重要：这也解释了为何 F28『无词表 / tokenizer-free』未继承在 A2.0 语境下不是缺陷 —— 协议明令禁止换词表。（F29 GlyphStream 属于 v2 新架构，与 A2.0 是不同路线）
- 铁律 2：A2.0 需检查中间维对齐；本路线因不替换而天然对齐
- 铁律 3：若将来执行 L2 β_l 校准或 A2.0 S4，此条必须重新启用
