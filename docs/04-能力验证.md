## ① 整层保真度

**方法**：teacher 整层输出 vs SimplCore 整层输出，余弦相似度。

⚠️ **方法论陷阱**（本项目的第一版测错过）：

```
✗ 错：mixer(h_in) vs attn_output
      SimplCore 的 mixer 内部自带 norm + 残差，外部不该再传 raw h_in
      teacher 侧也应比整层，不是只比注意力分支

✓ 对：teacher_block(x) vs simplcore_block(x)
      两侧都包含 norm + 残差 + FFN
```

**输入怎么造**：用 teacher embedding 的 μ/σ 采样，贴近真实激活尺度。

```python
mu, sd = emb.mean(), emb.std()
h_in = torch.randn(1, SEQ, D) * sd + mu
```

## ② 累积漂移

逐层堆叠：把上一层的输出喂给下一层，看相似度怎么衰减。

```
K=1   0.0573
K=2   0.0324
K=3   0.0278
...
K=28  0.0043
```

**裸迁移下衰减极快** —— 这是预期的，因为每层都在放大误差。
蒸馏后这个曲线会显著变平，**这是衡量蒸馏效果的最佳单一指标**。

## ③ O(1) 状态（SimplCore 最核心的特性）

```python
for B in (1, 2, 4, 8):
    model(torch.randint(0, V, (B, 64)))
    print(model.stream_bytes(1))

for L in (32, 64, 128, 192):
    model(torch.randint(0, V, (1, L)))
    print(model.stream_bytes(1))
```

**实测全部 = 274,432 B，唯一状态数 = 1。**

对照：
```
Qwen3 KV cache = 2 (K,V) × 2 (bytes/fp16) × 8 (KV头) × 128 (head_dim) × 28 (层)
               = 114,688 B / token
L = 1M  →  106.8 GiB
本模型   →  0.262 MiB（恒定）
```

## ④ 长上下文外推

```python
for L in (256, 512, 1024, 2048):
    out = model(torch.randint(0, V, (1, L)))
    assert torch.isfinite(out).all()
```

| L | logits 有限 | max\|logit\| | 状态 |
|---:|---|---:|---:|
| 256 | ✅ | 4.18 | 274,432 |
| 512 | ✅ | 4.49 | 274,432 |
| 1024 | ✅ | 4.82 | 274,432 |
| 2048 | ✅ | — | 274,432 |

**状态在 8× 长度变化下完全恒定** —— 这是 Transformer 做不到的。

## 判读标准（写给使用者）

| 余弦 | 含义 |
|---:|---|
| > 0.95 | 该层功能等价 |
| 0.8 – 0.95 | 基本可用，需少量微调 |
| 0.5 – 0.8 | 明显失真，必须继续蒸馏 |
| < 0.5 | 不可用 |

**裸迁移 = 0.057 → 属于"不可用"，必须蒸馏。**
**这不是方案失败，这是预期状态** —— 见 [00-协议总览](00-协议总览.md) 设计哲学 ①。
