# 06 · 踩坑记录：静默 bug 全集

> 本项目的 bug **全部不报错**。它们只是让结果悄悄变差一个数量级。
> 这份清单是本仓库最有价值的资产之一。

---

## 1. 自训词表替换 → 毁掉整个模型（最严重）

**现象**：模型完全不能说话。

**原因**：为"看不出 Qwen 风格"，把词表从 151936 换成自训 8192。
结果 embedding + head 共 **311M 参数变成随机初始化**，占总参数 47%。

**为什么致命**：
```
FFN/attention 迁移得再好，输入是随机 embedding → 一切归零
```

**修法**：**迁移时必须保留原词表。** 去风格化应该靠后训练（SFT 数据），
不是靠换词表。

**检测**：迁移后立刻检查 `vocab_size` 是否等于 teacher 的。

---

## 2. `coef` 形状不匹配 → 静默跳过

**现象**：mixer 保真度异常低。

**原因**：迁移时存了 `coef` 形状 `(32,)`，但模型需要 `(32, D)`。
加载函数做形状检查 → **不匹配就静默跳过** → coef 保持随机。

**为什么没被发现**：加载函数返回 `loaded/total`，但当时没打印。

**修法**：
```python
if t.dim() == 1:
    t = t.unsqueeze(1).expand(-1, D).contiguous()
```

**实测**：修完之后保真度**没有提升**（0.0655 → 0.0347）。
说明 coef 不是瓶颈，但**这个静默跳过的模式本身必须修**。

**检测**：加载后打印 `loaded/total`，必须 > 99%。

---

## 3. `ffn_ratio` 未设置 → FFN 权重全部跳过

**现象**：整层输出像噪声。

**原因**：`SimplCoreConfig.hidden` 默认 = `dim × ffn_ratio(2.0)` = 2048，
而 Qwen3 的 FFN 中间维是 **3072**。形状不匹配 → **静默跳过** → FFN 全随机。

**修法**：
```python
c.ffn_ratio = 3.0        # 1024 × 3 = 3072
assert c.hidden == FF
```

**检测**：这个 bug 修掉后，FFN 保真度从 0.057 → **1.0000**。

---

## 4. 残差流尺度爆炸 → loss 不收敛

**现象**：深层训练梯度爆掉。

**原因**：残差流随层数急剧放大：

| 层 | σ | max |
|---:|---:|---:|
| 0 | 0.0293 | 0.155 |
| 27 | **33.78** | **7187** |

**相差 1000 倍**，裸 MSE 在深层量级巨大。

**修法**：
```python
YS = float(Y.std())
loss = F.mse_loss(out / YS, Y / YS)
```

---

## 5. `sys.insert` vs `sys.path.insert`

**现象**：`AttributeError: module 'sys' has no attribute 'insert'`

**原因**：写成了 `sys.insert(0, p)`（少了 `.path`）。

**教训**：Python 不会报"你是不是想写 sys.path"，只会说 sys 没有 insert。

---

## 6. LD_LIBRARY_PATH 拼接时机

**现象**：`ImportError: libcusparseLt.so.0`

**原因**：在 torch **安装之前**就拼了 `LD_LIBRARY_PATH`，
那时 `nvidia/*/lib` 还不存在，`$(echo ...)` 得到空字符串。

**修法**：**必须在 torch 装好之后**再拼：
```bash
[ -d "$DIST/torch" ] || bash setup_torch.sh
export LD_LIBRARY_PATH="$(ls -d $DIST/nvidia/*/lib | tr '\n' ':')$LD_LIBRARY_PATH"
```

---

## 7. 张量维度多一层

**现象**：`ValueError: too many values to unpack (expected 3)`

**原因**：缓存时 `torch.stack([x for ...])` 得到 `(N, 1, SEQ, D)`，
索引 `X[i:i+1]` 仍是 4 维，但 SGC 期望 3 维。

**修法**：用 `X[i]` 而非 `X[i:i+1]`。

---

## 8. 层号取错 → 只迁移了第 0 层

**现象**：迁移看起来成功，能力很差。

**原因**：解析 `blocks.{i}.mixer.*` 时层号在 **seg[1]**，代码按 **seg[2]** 取，
恒得 1 → **只迁移了第 0 层**。

**检测**：迁移后打印成功迁移的层数。

---

## 9. bf16 更新被舍入 → loss 纹丝不动

**原因**：可训练参数存成 bf16，Adam 的小更新（1e-5 量级）被舍入掉。

**修法**：**可训练参数强制 fp32**。

---

## 10. 替换 `block.forward` 切断 autograd

**原因**：为了 hook 而 monkey-patch `block.forward`，
导致梯度恒为 0（autograd 图断了）。

**修法**：用 `register_forward_hook`，不要替换 forward。

---

## 11. `\n` 占据 id0 = unknown → 换行全丢

**原因**：`sorted()` 把换行排最前，而 `CharTokenizer` 的 unknown_id 默认就是 0
→ **所有换行被判为 unknown 而丢弃**。

**后果**：生成的代码全挤一行，注释吞掉函数定义，`exec` 必然失败。

**修法**：用 `\x00` 占住 id0。

---

## 12. 名字空间不足导致的死循环

**现象**：脚本卡死 12 分钟无输出。

**原因**：名字空间只有 400 个，要生成 3000 个不重复函数名时
`if name in used: continue` 永远找不到新名字。

**修法**：按需动态扩展名字空间，或加最大尝试次数后 fallback。

---

## 通用防御清单

```python
# 每个加载函数都必须返回并打印覆盖率
loaded, missing = load_weights(...)
print(f"loaded {loaded}/{total} = {loaded/total*100:.1f}%")
assert loaded / total > 0.99, "有张量静默跳过！"

# 每个形状断言都要显式
assert c.hidden == FF, f"hidden={c.hidden} != FF={FF}"
assert c.vocab_size == teacher_vocab
```

**原则：任何形状检查失败都必须大声报错，不能静默跳过。**
