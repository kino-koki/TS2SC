# 02 · 核拟合：Attention → SGC

## 为什么能做

自注意力按**相对距离**平均后，会收敛成一个 Toeplitz 核 ā[τ]：

```
ā[τ] = E_{batch, head, pos} [ A[pos, pos-τ] ]
```

也就是说：**"平均意义上，模型在距离 τ 处放多少权重"** 是一个只依赖 τ 的函数。

而 SGC 的核是：

```
Ψ[m, τ] = ρ_m^τ · sin((τ+1)·θ_m)      m = 1..M（基函数个数）
```

**Ψ 对系数 c 是线性的**，所以可以直接闭式求解：

```
c* = lstsq(Ψᵀ, ā)
```

**不需要训练，一次最小二乘即可。**

---

## 完整流程

```
① teacher 前向，抓 attention 权重（需 attn_implementation="eager"）
        ↓
② 按相对距离 τ 平均 → ā[τ]，τ = 0..max_tau-1
        ↓
③ 归一化（Σ ā = 1）
        ↓
④ 构造 Ψ 矩阵：M 个振荡基 × max_tau 个距离
        ↓
⑤ lstsq 求 c*
        ↓
⑥ c* 写入 mixer 的 coef / raw_rho / raw_theta
```

---

## 基函数的物理含义

| 参数 | 含义 | 影响 |
|---|---|---|
| `ρ` (raw_rho) | 衰减率 | ρ 大 = 长程记忆，ρ 小 = 局部 |
| `θ` (raw_theta) | 振荡频率 | 决定核的周期性 |
| `coef` | 基组合系数 | 各基的加权 |

**实测层次分化**（Qwen3-0.6B）：

```
layer 0  τ90 = 42    → 局部（语法、邻近词）
layer 2  τ90 = 182   → 长程（主题、远距离依赖）
```

τ90 = 累积到 90% 注意力质量所需的距离。
**这个分化证明核拟合确实抓到了 teacher 的结构，不是噪声。**

---

## 残差：当前瓶颈与真相

实测残差 **0.0773**（Qwen3-0.6B，M=32 基）。

**这个数字看起来不错，但具有误导性** —— 因为：

1. ā 是**平均**核，拟合得好不等于逐 token 行为一致
2. 注意力是**输入相关**的：同一位置，不同输入内容，注意力分布完全不同
3. SGC 是**输入无关**的：一次拟合，永远用同一个核

**所以核拟合做得再好，也补不上 content-based routing 的缺失。**

实测佐证：

```
裸迁移 mixer 保真度 = 0.1024     ← 残差 0.0773 却只有 0.10 保真度
```

**残差低 ≠ 性能好。** 这是本项目最重要的负面结论之一。

---

## 增加基函数有用吗

| bases | 残差 |
|---:|---:|
| 8 | 0.74 |
| 32 | 0.37 |

残差确实下降，但**最终性能几乎不变**（5.5519 → 5.5425）。

**结论：残差不是当前瓶颈，加大 bases 性价比很低。**
真正的瓶颈是"输入无关"这个结构限制，只能靠蒸馏补偿。

## 代码实现要点

```python
# 抓注意力
teacher = AutoModelForCausalLM.from_pretrained(
    path, attn_implementation="eager", output_attentions=True)
out = teacher(**batch)          # out.attentions: tuple[L] of (B, H, L, L)

# 按 τ 平均
for li, A in enumerate(out.attentions):
    for tau in range(max_tau):
        diag = torch.diagonal(A, offset=-tau, dim1=-2, dim2=-1)
        a_bar[tau] += diag.mean().item()
a_bar /= a_bar.sum()

# 构造 Ψ 并求解
Psi = torch.stack([rho[:,None]**t * torch.sin((t+1)*theta[:,None])
                   for t in range(max_tau)], dim=-1)   # (M, max_tau)
c = torch.linalg.lstsq(Psi.T, a_bar).solution
```

⚠️ **必须 `attn_implementation="eager"`**。用 sdpa / flash_attention 时
`output_attentions=True` 返回的是 `None` 或错误结果，**且不报错**。
