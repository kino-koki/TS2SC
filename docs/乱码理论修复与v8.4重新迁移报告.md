## 一、乱码的理论根因（精确复现，不是猜测）

### T1 数值层：NaN 静默退化成哨兵 id

```
未校准 β·o (真实 Wk/Wv 读出 1e4~1e5)
  → x+Δ 把 teacher 残差推离 O(1) 尺度
  → RMSNorm: mean(x²)=inf → 1/sqrt(inf)=0, inf·0=nan → 全层 nan
  → lm_head 分块 logits 全 nan
  → TeacherLM.logits:  `if lg[j] > best_v`  中 NaN > x 恒为 False
  → best_i 初始哨兵 -1 永不更新
  → 24/24 个生成 id 越界
  → 解码器查不到 token，逐字丢弃 → 空串
```

`scale_theory.py::nan_to_sentinel_demo()` 可独立复现 `best_i=-1`。
**这不是 UTF-8 mojibake，是「连乱码字符都没产生」的最坏形态**，而且不抛异常、
不报警——V7 的 `gen_quality` 只测 `distinct1/rep3`（R4 根因），完全漏检。

### T2 信息层：role bit 的可分辨性依赖 k 的偶然尺度

第一轮我先写成「role one-hot 被 1e2 量级的 k 淹没」，**真实权重上跑出来是错的**：
实测 `r_k = 0.324`。F26 断言当场 FAIL（`amplification 0.16`，方向反了）。

正确的理论缺陷是**尺度依赖**，不是「总被淹没」：

```
naive (v8.3):  ρ = ‖e‖ / ‖k‖ ∝ 1/r_k
   r_k=0.32 → ρ≈3   role 反而主导、扰动 k 的语义
   r_k=1e2  → ρ≈0.01 被淹没
   跨 1e4 倍输入尺度衰减 10000× → 名义 B=log₂R 时稳时不稳
```

即论文 Theorem 3 的输入侧预算**没有被稳定兑现**：B 是否可读出取决于这一层
输入的偶然幅度。长程内容寻址因此错乱，表现为「语义乱码」。

### T3 验收层：非退化代理根本测不出这件事

空串、`-1`、NaN 都不触发 `distinct1/rep3` 的失败条件。验收口径本身有洞。

## 二、可证修复（不是 clip，不是焊系数）

### T1′ 无量纲尺度契约

令 `r_x=‖x‖₂/√d`, `r_o=‖o‖₂/√d`, `û=o/(r_o+δ)`，注入

```
Δ(x,o) = β · ε · r_x · û ,   ε = 0.10
```

**命题**：`‖Δ‖₂ = βε‖x‖₂ · r_o/(r_o+δ) ≤ βε‖x‖₂`。

推论：

- `‖x+Δ‖ ≤ 1.1‖x‖` ⇒ RMSNorm 输入有界 ⇒ **overflow 不可能发生** ⇒ logits finite ⇒ id 必合法。
- `β=0 ⇒ Δ=0` ⇒ 与 teacher 逐位相同（F11 I1 保持）。
- `r_o` 吸收 o 的原始量级（1e4 或 1e-5 都一样），**与 teacher 解耦**。
- β 变成 **[0,1] 里的无量纲比例**：L2 校准的是比值，不再是去拟合 1e-5 量级的怪系数。
- **clip 被移除**——v8.3 的归一化+clip 是掩盖，契约是约束。

实测：`scale_theory.py` 在 `mag ∈ {1e-5, 1, 1e4, 1e5}` 上比值全部 `≤0.100001`；
真实 Wk/Wv 分支上 `delta_norm 0.0986 ≤ bound 0.0991`。

### T2′ 尺度不变 role 注入

```
k̂ = k/(r_k+δ)   (单位 RMS)
k'_r = k̂ + snr·e_r ,   snr = 0.50
```

**命题**：

- (i) `‖k'_r − k'_s‖ = snr·√(2·n_r)`，**与 ‖k‖ 完全无关**；
- (ii) role 相对能量比恒定，跨 1e4× 尺度 **CV = 0**；
- (iii) B=0 时所有假设相同，距离 0。

对比：naive 的 ρ 跨同尺度衰减 **10000×**。
同时把 **k 的绝对幅度交给 F10 写入门**控制，role 只携带输入侧信息 `B=log₂R`——
两者解耦，正合 Theorem 3 + gated consolidation 的分工。

### T3′ finite-and-in-range 解码守卫

- `TeacherLM.logits` 的 `best_i` 初始从 `-1` 改为合法 `0`，并上报 `last_logits_finite`；
- `decode_gate(ids, V, finite)` 显式拒绝 NaN / 越界 id / 空串；
- 取代「非退化即通过」。
