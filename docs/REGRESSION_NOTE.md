## 根因（算得出来，不是猜）

| 部分 | 字节 |

本轮是**边界失败**，两者同一份代码、同一组数值。

## 本轮对代码做了什么（只降峰值，不改数值）

且 `Generator` 状态连续 ⇒ 随机序列与一次大调用**逐位相同**。

自检（真跑）：

```
sequence identical: True
```

因此 C1 的 sha256 集合、C5 的 Δlogits、C6 的输出序列**全部不变**，
`pure_backbone_v11_verify.json`（20:14 全绿）仍是有效证据，未作废、未改写。

降峰值后仍 137 ⇒ 限制来自**常驻 3.40 GiB 本身**，不是构造临时数组。
要在此沙盒稳定复跑需把 embed/lm_head 改 BF16 存储（与 teacher 一致）或换
更大内存环境；本轮**不改模型数值定义**，不为了「复跑全绿」去动已验证的架构。
