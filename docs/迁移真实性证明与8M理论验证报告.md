## 一、证明「不是原模型直接跑」（`migration_proof.json`）

### E1 结构级 · 集合差集

```
teacher keys   = 219
student keys   = 411
COPY 逐位保留  = 219   （removed = 0）
新增           = 192   （72 DERIVE + 120 NEW，全部 sgc/blocks）
```

原模型的 state_dict 里**根本不存在**这 192 个名字。其中 **144 个已真实落盘**
在 `student_branch_v8.safetensors`（216.6 MiB），可打开逐字节读、带 sha256、
Wk/Wv 的 shape 已从 teacher 的 `[kv_dim=256, 1536]` 派生成 `[1536, 1536]`。
> 若只是跑原模型，这 192 个张量不可能存在，更不可能被逐层读进前向。

### E2 因果级 · 同进程三路反事实

唯一变量是 hook，权重/prompt/seed 全同：

| 臂 | 配置 | 结果 |
|---|---|---|
| a | 无 hook（纯原模型） | 基准 |
| b | 挂 hook 但 `enabled=False` | **与 a 逐位相同** |
| c | 挂 hook `β=1` 契约态 | 与 a 不同 |

`cache[l][0]` 是第 l 层 attention 的 K，由该层**输入**决定：

```
layer 0 delta = 0.000000     ← 输入是 embedding，还没经过任何 hook，必然不变
layer 1..23   = 3.40 → 26.61  ← 23/23 全变，随深度递增
```

**23/24 不是失败，是因果正确性的正面证据**：第 0 层若也变了反而说明度量串了。
逐层递增证明 24 个 hook 逐层生效、扰动向前传播，不是只改最后一层。

### E3 归因级 · 分支权重消融（两个真发现都写进来了）

| 扰动 | `d(a,·)` | `d(c,·)` | 读法 |
|---|---|---|---|
| 真实派生权重（c） | **58.1443** | — | 迁移态确实不同于 teacher |
| 全置零 | **0.0000** | 58.1443 | 差异**完全消失** ⇒ 由新权重产生 |
| ×0.5 缩放 | 58.1443 | **0.0001** | 见下「发现 1」 |
| 行置换（改方向） | 59.8089 | **74.5976** | 输出明显不同 ⇒ 归因成立 |
| 随机位模式 | 0.0000 | 58.1443 | 见下「发现 2」 |

- **发现 1（尺度不变）**：`Wk/Wv ×0.5` 几乎不改变输出，因为 T1′ 契约的
  `u = o/(r_o+δ)` 把**全局幅度归一化掉、只保留方向**。这是无量纲设计的必然结果，
  也说明「缩放」不能做权重归因——所以改用**行置换改变方向**重做，才拿到 74.6 的硬差异。
  这个发现没有抹平，单列在报告与 JSON 里。
- **发现 2（守卫生效）**：纯随机 uint16 位模式含 BF16 NaN/Inf ⇒ `k⊗v` 变 NaN ⇒
  `nan_to_num` 把非有限分支吞成 0 ⇒ 等于 teacher。这是 T1′ 守卫起作用的观察，
  不是失败，但同样不能做归因。

**结论**：β=1 的差异确实由这 192 个迁移新增张量产生，且对权重**结构/方向**敏感；
不是数值噪声，不是 teacher 自身，也不是「原模型直接跑」。

### E4 完整性

22 分片 **2,161,290,912 B** 全量 sha256、`size_match=True`、重组 sha256 留档；
411 张量 `UNCLASSIFIED=0`；144 张量 checkpoint 重开逐位复验通过。

## 四、8M Token 上下文 · 理论验证（`context_8m_theory.json`）

用真实 `config.json`（`d=1536, nl=24, nq=16, nkv=2, hd=128, max_pos=131072, θ=5e6`），
`L = 8,388,608`。**分三层，含反例条件，不吹「支持 8M」**：

### A · SimplCore 构造（SGC 分支）— 成立

```
单层状态  = R×ds×ds×4 + (K-1)×d×4 = 1,585,152 B
24 层合计 = 38,043,648 B = 36.28 MiB        ← 与 L 严格无关
FFT 对偶  ≈ L·log₂L = 1.93e8 蝶形；IIR 递推不需 O(L) 缓冲
输入侧 B ≥ log₂|A(v)| 是 per-fibre 计数下界 ⇒ 不随 L 增长（F26 已保证 role 可分辨）
```
**理论结论**：静态 Toeplitz + IIR 递推在 8M 下状态仍是常数，且 F05 实测过
`L=1/4/16/64` 状态字节恒定。这一层**成立**。

### B · 当前 hybrid 迁移 — 端到端不可行

因为「融合而非替换」，teacher softmax attention **一层没删**：

```
KV cache / token / 层 = 2×nkv(2)×hd(128)×2B = 1024 B
8M × 24 层            = 206,158,430,208 B ≈ 192 GiB
全因果 attention 对    ≈ 10^16.1
RoPE 外推倍数         = 8,388,608 / 131,072 = 64× （rope_scaling=None）
```
SGC 的 O(1) 状态**不能替 teacher 路径付 KV cache 的钱**。

### C · 要达到 8M 的可证条件（未实现）

1. teacher 路径改局部窗/滑窗 W，长程检索交给 SGC 分支：`W=4096 ⇒ 24 层 KV ≈ 96 MiB`，显存可行；
2. 或分层路由（浅层 teacher 局部窗、深层 SGC 全局）——但**动了 teacher attention，与「融合不替换」红线冲突**；
3. RoPE 需 NTK/YaRN/位置重标定才能外推 64×；SimplCore 静态核是平移不变 Toeplitz，本身不依赖绝对位置。

> **实测边界**：本轮最长只到 **28 prompt + 24 生成 = 52 token**。
> 8M 是 SGC 分支的**理论性质**，不是当前迁移模型的**已验证上下文长度**。
