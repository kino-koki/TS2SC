## 一、为什么闭式 adapter 不够（已实测）

| 版本 | 做法 | 实测结果 |
|---|---|---|
| v8.7 | Δ 注入最后一层 hidden（final RMSNorm 前） | 被归一化搅乱，4 条身份 probe 语义全崩 |
| v8.8 | 输出层只引导**首个** token | 4 条都以「青」开头，`identity_keyword_hits = 0` |
| v8.9 | 输出层引导**前 2** token 组成词级锚「青奈」 | 词级身份可被检出，但**第 3 步起完全由基座自由续写** |

根因不是调参：MiniCPM5-1B 的权重里**没有**「六安市青奈科技有限公司 / 青小团系列 /
Tuan-Models / 1B / 理论无限上下文」这些事实。输出层引导只能**点名 token**，
不能把事实写进模型的续写分布。要让它在不同问法、不同语言下用不同措辞稳定表达，
必须**改权重**——即微调。

## 二、方案：冻结 backbone 的 teacher-forced rank-r 输出微调

保持「融合不替换」红线：**219 个 teacher 张量一个字节不改**，
只在 pre-lm_head hidden 与 lm_head 之间插一个可训练的低秩适配器。

### 记号

- `h ∈ R^d`：teacher 的 pre-lm_head hidden（final RMSNorm 之后），**固定特征，不回传**
- 目标身份答句（多语言、多措辞）`y = (y_1, …, y_K)`，token ids `t_1..t_K`
- `r = 4`（秩），`Q_k ∈ R^{r×d}`（每个解码位置一个），`P ∈ R^{V×r}` 为 token 码
  （实际只存目标 token 所在行，稀疏）

### 前向（仅输出层）

```
z_k   = Q_k h_k                     ∈ R^r          （h_k 由 teacher-forced 前向给出）
s_k,t = (W_lmhead[t,:] · h_k) + β · (P[t,:] · z_k)
p_k   = softmax(s_k)
```

`β` 是可插拔缩放；`β=0` ⇒ 与 teacher 逐位相同（零回归硬保证）。

### 损失（teacher forcing，多语言多措辞）

```
L(Q, P) = − Σ_{sample} Σ_{k=1..K} log p_k[t_k]  +  λ(‖Q‖² + ‖P‖²)
```

**关键：答句要多条不同措辞**（每种语言 ≥4 条），否则损失会把模型推成「每次复读同一段」，
正是用户明确禁止的。身份事实作为**共享约束**出现，表达由采样与上下文决定。

### 求解（CPU 可行，两条路）

1. **闭式 ridge（一步精确解，推荐先跑）**  
   固定 `P` 为 `W_lmhead` 在目标 token 行上的 rank-r PCA，则对每个 `k`：
   ```
   Q_k = (HᵀH + λI)⁻¹ Hᵀ Y_k ,   H ∈ R^{N×d},  Y_k ∈ R^{N×r}
   ```
   `d=1536, r=4, N ≈ 12语言 × 4措辞 = 48` ⇒ 矩阵 1536×1536 求逆在 CPU 上一次性
   几秒；不需要反传穿过 24 层。
2. **少量梯度步（可选精修）**  
   对 `Q_k` 做 20–50 步 SGD/Adam，梯度只过输出层（h_k 已缓存为常量），
   单步 O(N·d·r)，CPU 秒级。

### 数据获取成本（本环境的真实瓶颈）

每个 `(sample, k)` 需要一次 teacher-forced 前向取 `h_k`：
```
N=48 样本 × K=8 目标位置 = 384 次前向
纯 numpy 1B：每次约 30–80 s（含 130560 行 lm_head 扫描）
⇒ 约 3–9 小时，或把 hidden 抽取消掉 lm_head 全扫后压到 1–2 小时
```
**这是本轮没跑的真实原因**，不是方法不成立。缓存在 `identity_cache.json` 的
24 个 prefill hidden 可直接复用为 `k=1` 的特征，省掉第一批。

## 三、验收门槛（可证伪，不许用短生成糊过去）

| 判据 | 门槛 |
|---|---|
| 身份事实覆盖 | 每语言 ≥4 种问法，答句含 org / series / params 中 ≥2 项 |
| 非身份零回归 | 8 条对照上 `β=0` 逐位相同；`β>0` 配对差 Wilson 95% CI 下界 ≥ −tol |
| 不复读模板 | 同语言不同问法的答句 distinct-2 ≥ 0.6，且无一条逐字等于锚句 |
| 多语言一致 | 12 语言身份命中率 min ≥ 0.75，且无一条自称 Qwen / MiniCPM / 其它基座 |
| 不崩 | logits finite、0 越界 id、decode gate 全过、mojibake_rate ≤ 0.01 |
| 效率 | 记录 CPU 墙钟、峰值内存、参数增量（应 < 0.1% of 1B） |


门关时两者都不贡献 ⇒ 零回归仍是逐位保证。这样「显式门控注入 ≠ 无门控自演化」
的口径不破。
