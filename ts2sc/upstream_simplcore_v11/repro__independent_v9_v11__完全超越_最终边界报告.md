# SGC 冻结 + 外挂：六轮完整开发后的「完全超越」真实边界

> 全部产物：`decisive_v6.py`（最终协议）、`decisive_v6_results.json`（最终原始结果）、
> `final_decisive.py`（边界判定）、`complete_beyond*.py`（迭代链）、`SGC冻结外挂_超越与不足_完整报告.md`（上一版）
> 一键复现：`python decisive_v6.py`；环境/seed/sha256 写入每个 JSON 的 `fingerprint`

---

## 0. 直接结论（不喊口号）

在**完全保留 SGC 全部特性**（静态 Toeplitz 核 `ψ_m[τ]`、FFT↔IIR 双形式、O(1) 定态、无位置表/无 max_len）+ **纯度/CI 全过** 的硬约束下：

- **「完全超越」在可行性 / 成本 / 纯度 / 确定性四根轴上真实成立**，有 REAL_RUN 实跑 + 确定性代数判据。
- **「完全超越」在语言建模质量轴上不可达**：同分布与不规则 dt 可以靠过完备谱基字典堆到 parity，但**长度外推 LM 质量始终达不到严格优**，M 堆到 1024 仍不达标，给 attention 2× 训练步数后差距反而扩大。
- 这不是「还没调好」：六轮里我推翻了自己两次错误结论、修掉全部公平性缺陷、给对手加了 ALiBi 与更多预算，结论稳定。

一句话：**能完全超的是「attention 结构性跑不动的地方」，不是「attention 训练充分后还更准的地方」。** 这与仓库 README 自承的「所有优于 Transformer 的主张都是机制层结构性质，不是实测的质量结论」一致。

## 2. 决定性数据

### 2.1 过完备谱基字典（M = 谱基数量，`coef[m,d]` 可训练）

| M | M/D | A1 同分布 Δ | A2 长度外推 Δ(最小) | A3 不规则 dt Δ | SGC 参数 | 常驻状态 |
|---|---|---|---|---|---|---|
| 256 | 8 | +0.057 ✗ | +0.149 ✗ | **+0.006 ✓** | 37,886 | 8,192 B |
| **512** | 16 | **+0.041 ✓** | +0.085 ✗ | **+0.033 ✓** | 63,230 | 16,384 B |
| 1024 | 32 | +0.086 ✗ | +0.069 ✗ | +0.058 ✗ | 113,918 | 32,768 B |
| attention 对照 | — | 基线 4.329 bpc | — | — | 17,150 | O(L) KV |

- **A1、A3 在 M=512 达成「不劣」（阈值 0.05，3 seeds 均值）**，但代价是参数量变成对手的 **3.7 倍**、状态 16 KB。
- **M 再翻倍到 1024 全面回退**（过参数化 / 优化困难），不是单调可堆。
- **A2 从未达成严格优**，且 seed 方差大（seed33 各配置都显著更差）。
- **公平对照**：给 attention 2× 训练步数后我方 A1 变成 **+0.352**，说明对手不是欠训，越训越强。
- 结论：谱基容量能买回「同分布质量 parity」，买不回「长度外推严格优」。

### 2.2 解析自由度（IDENTITY，确定性）

| | 成对交互自由度 | 是否随输入变化 |
|---|---|---|
| SGC 静态 Toeplitz 核 | **O(M)**，矩阵由 `ψ[τ]` 生成 | 否 |
| attention `softmax(q·k)` | **O(L²)** | 是 |

堆 M 最多把 O(M) 提到与 L² 同阶（状态/算力同步爆炸），**永远补不上「随输入变化」**——因为那正是破坏 Toeplitz/FFT 对偶的定义。这是 A2 卡住的解析原因。

### 2.3 可行性「完全超越」（REAL_RUN + 确定性代数，零波动）

- **弃用** v4 的 `2s wall-clock` 判据：两次复跑 2.58s / 1.74s 判定翻转，不合格。
- **改用确定性内存上界**：attention 必须物化 `8·L²` 打分矩阵 + `2·L·D·8` KV；SGC 状态 `2·M·16` 与 L 无关。

| HBM 预算 | attention L_max（打分矩阵约束） | SGC |
|---|---|---|
| 0.5 GiB | 8,192 | 无上限 |
| 2 GiB | 16,384 | 无上限 |
| 80 GiB | 103,621 | 无上限 |

REAL_RUN 计时趋势（仅佐证，不用于判定）：

| L | SGC 单步 / 状态 | attention 单步 / 打分矩阵 | 倍率 |
|---|---|---|---|
| 1024 | 0.0047 s / 1,024 B | 0.030 s / 8.9 MB | 6.4× |
| 4096 | 0.015 s / 1,024 B | 0.411 s / 136 MB | 27.7× |
| 8192 | 0.027 s / 1,024 B | 1.435 s / 541 MB | **53.6×** |

### 2.4 纯度 / 真实性硬闸门（REAL_RUN）

- **真·调用仓库 `purity.py`**：`importlib` 直接 exec 源文件，跑 `assert_pure_config` / `scan_source_attention_free` / `assert_attention_free` / `_identifier_hit`；6 项负向变异（含改名绕过）全被抓；产品源码零命中 → **12/12 / 13/13 PASS**。
- **端到端反传中心差分校验**：两臂最差 **4.1e-11**（逐参数）。
- **FFT ↔ 直接因果卷积逐位等价** 5.3e-15；核静态 Toeplitz 断言；P8 AST 零处写 `self.basis[...]`。
- **独立复跑**：数值字段零差异；全程 seed/环境/sha256 固定。

## 3. 超越的地方（真实成立，逐条标 level）

1. **常驻状态 O(1) 与 L 无关**：1–32 KB（随 M），attention O(L) KV → `LEDGER_ALGEBRAIC`
2. **单步成本 O(L·M) vs attention 必物化 O(L²) 打分矩阵**：L=8192 实跑 53.6× → `REAL_RUN`
3. **长上下文可行性**：超过 HBM 预算后 attention 代数不可行，SGC 仍可跑 → `REAL_RUN + 确定性判据`
4. **无位置表 / 无 max_len 截断 / 严格因果流式**：`IDENTITY`
5. **同分布与不规则 dt 质量可堆到 parity**（M=512：A1 +0.041、A3 +0.033，均在 0.05 不劣线内）→ `REAL_RUN`
6. **纯度/CI**：真仓库守卫全过、无 QKV/softmax/SDPA/KV cache/位置表 → `REAL_RUN`
7. **可复现性**：端到端训练、梯度精确、独立复跑零差异、纠错链留档 → `REAL_RUN`

## 4. 不足 / 不能宣称的地方（全部列出）

1. ❌ **质量轴「完全超越」不可达**：`QUALITY_COMPLETE = False`（M=256/512/1024 三档全未达成）。
2. ❌ **A2 长度外推 LM 质量从未严格优**：最小 Δ +0.069 ~ +0.149 bpc，且 seed 方差大；静态核长 L 分布漂移 + 无归一化动态聚合。
3. ❌ **parity 的代价被诚实记账**：M=512 时 SGC 参数 63,230 vs attention 17,150（**3.7×**），状态 16 KB；**上一版「1/5 参数」的宣称已作废**。
4. ❌ **M 不可无限堆**：1024 全面回退；给 attention 更多训练反而拉大差距（+0.352）。
5. ❌ **对照臂已给足但仍非完整 Transformer**：单层 attention + ALiBi + 可学位置 + 同等/2× 训练；无多头、无 FFN、无 layer norm、无真实 tokenizer。
6. ❌ **真实语料规模极小**：莎士比亚 240 KB、62 字符词表、D=32、L=48、1600 步。**PPL/通用 LM 质量结论不适用**。
7. ❌ **1B+ / 中文语料 / LRA / 长文档 / 多 needle / 层级运算：完全未测**。
8. ❌ **精确逐字指向 / 任意 O(L) needle**：定容状态信息论上限，仓库 README 自承。
9. ❌ **等价实现非仓库源码执行**：沙盒无 torch，`FrozenSGC`/`SGCArm` 是按仓库公式写的 numpy fp64 等价黑盒；CI 真调了仓库 `purity.py`，但**没跑仓库 pytest 套件**。
10. ❌ **fp16/bf16 数值、长核误差累积、HIP 16-op 契约、`--train-chunk`、多卡 DDP 未测**。
11. ❌ **线性/端到端 head 已训，但写入质量依赖生成器的 pair 结构**：真实流式需学出 L1 门，未验证。
12. ❌ **计时曲线受机器负载影响**：已明确降级为趋势佐证，不用于判定。
13. ❌ **无第三方独立复现**：仓库 0 star/0 fork，本包是我沙盒内自洽复现。
14. ❌ **证据链是「机制层可运行断言」**，不是同行评审或实测 SOTA。

## 5. 要「全轴完全超越」必须放弃什么（逐条给代价）

| 放弃的约束 | 得到 | 代价 |
|---|---|---|
| 核静态 Toeplitz → 让 `a/b/c` 随输入变（SRF / Mamba 选择性 SSM） | 补上「随输入变化」的自由度，A2 有机会 | 破坏 FFT↔IIR 对偶与 `O(L log L)` 训练路径；不再是 SGC |
| O(1) 状态 → 加 O(L) KV 或 O(N) 精确档案 | 精确召回 / 任意 needle | 效率主张消失，回到 Transformer / sidecar |
| 纯度 → 引入全局注意力层 | 直接拿到最强质量 | 不再是仓库定义的架构，CI 会拒 |

**这三条任意取一条，就不是「完全保留 SGC 特性」了。** 所以边界是定义性的，不是工程未及。

## 7. 一句话收束

**六轮之后，「完全超 attention」的准确表述是：在 attention 结构性失守的长度 / 成本 / 纯度 / 确定性轴上完全超越（实跑 + 代数判据，零波动）；在训练充分的 LM 质量轴上只能买到 parity，且要付 3.7× 参数、16 KB 状态，长度外推仍买不到严格优。仓库 README 那句「不是更好的模型，是唯一成本可行的选择」依然成立——我这次只是把「可行」和「不可行」都钉成了可复现的数字，并把自己两次错误结论留在了证据链里。**
