## 一、推翻了上一轮的「定义性边界」论断

v8 我写过「静态核的成对交互自由度 O(M) 且与输入无关，堆 M 永远补不上随输入变化 → 定义性边界」。**这个论证只对单层成立。**

多层堆叠时，第 l 层的输入 `U^(l) = A(X^(l))·σ(B(X^(l)))` 由上一层全局混合结果给出，再叠加层间 RMSNorm + FFN 非线性，有效成对交互变成**输入依赖**——而核 `ψ_m[τ]` 一字未动。所以那条边界不是定义性的，是单层的。

## 三、为什么仍判 False（两条互相独立的否决理由）

**1. 2× 对手步数对照失败 → 机械判定也 False**

给 attention 每步 2 次更新（3 seeds × 2000 步）：

| seed | A1 | A2min | A3 | 三轴 |
|---|---|---|---|---|
| 11 | +0.1156 | −1.3254 | +0.0419 | ✗ |
| 22 | +0.1835 | −0.6003 | +0.1755 | ✗ |
| 33 | −0.0688 | −0.4587 | −0.0176 | ✓ |

`fair_all = False`。对手越训越强，这不是欠训假象。

**2. A2 的「赢」全部是崩坏区伪影 → 主动收紧判据否决**

step6000 绝对 bpc（L48 基线 ≈ 4.6）：

| seed | L384 | L768 | L1536 |
|---|---|---|---|
| 11 | S5.21 / R5.11 | S7.18 / R7.12 `*` | S9.90 / R10.20 `*` |
| 22 | S5.67 / R5.72 `*` | S6.03 / R6.14 `*` | S9.09 / R8.69 `*` |
| 33 | S4.29 / R4.34 | S6.32 / R6.17 `*` | S12.24 / R12.50 `*` |

`*` = S 相对 L48 劣化 > +1.0 bpc。所有负 delta 都落在 L768/L1536，而两臂在那里 bpc 从 ~4.6 崩到 6~12（劣化 **+1.2 ~ +7.7**）——是「双方都烂、S 烂得稍慢」，不是质量超越。

新增 **EFFECTIVE 判据（明确标注：v11 事后新增，非预注册）**：赢所在 L 上 S 的 bpc 劣化必须 ≤ +1.0。收紧后：

- 有效外推区 `effA2min` 全为 **+0.0068 ~ +0.1494**（S 没赢）
- `stable_effective` 连续 **0**

我没有靠判据漏洞宣布胜利。

## 四、试过但无效的全部自由度

`层数 {1,2,3,4,6,8,10}` · `M {64,128}` · `lr {2e-3,3e-3}` · `FFN 隐宽 H {2D,4D}` · `残差缩放 β {1.0,0.5}`
· **每层独立固定谱字典（banded）**：同配置反而更差（A1 **+0.0108** / A2min **+0.0261** / A3 +0.0023）
· **EMA**：`0.995^1800 ≈ 1e-4`，shadow ≈ 在线权重，结果逐位相同，无效
· 两臂共享：长度归一化 / RMSNorm / residual / FFN / pre-norm Block / Sidecar / readout / 优化器 / seed / 数据 / 长度课程 / dt 增广
· 更强对手：纯 ALiBi **无位置表**（去掉可学位置表这个伪影源）、2× 训练步数、OOD 推到 L384/768/1536
· 前向与反传都走 FFT `O(L log L M)`（贴合仓库 `torch.fft` 训练路径）

## 五、两次抓到的假胜（留档，未抹除）

1. **α=0.75 长度归一化初版只加在 SGC 臂** → A1 −0.50 / A2 −0.60 / A3 −0.58 的漂亮假胜。改成**两臂共享 Block 级**后归零；反向对照证实「谁拿偏置谁赢」（`sgc_only` 全轴大胜、`attn_only` 全轴大败）。任何只在单臂出现的结构增益一律不计入判定。
2. **v11 的 A2 只看 delta 的判据漏洞** → 加绝对 bpc 约束收紧。
